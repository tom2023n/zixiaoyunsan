# 字消云散

一款汉字消消乐网页小游戏：棋盘上散落着一堆字块，按顺序点字连成词语、成语、古诗句，或把偏旁部件拼成一个字，连对即消除。清空所有字块即可过关。

> 受同类汉字消除玩法启发的非官方作品，与任何商业游戏无关。题库为自行整理的常用词语、成语、诗句与部件拼字；全部图形、图标、音效均由代码实时生成，不包含任何第三方素材。

## 在线游玩

- 网址：https://tom2023n.github.io/zixiaoyunsan/
- **iPhone**：用 Safari 打开 → 分享 → “添加到主屏幕”，即可像 App 一样全屏启动；首次打开后可离线游玩。
- **安卓 / 电脑 Chrome**：地址栏右侧“安装”图标即可安装。

## 玩法

- 四种题型轮换：**词语**（2 字，按顺序）、**成语**（4 字，按顺序）、**拼字**（2 个部件，不分先后，如 氵+工=江）、**诗句**（5 字，按顺序）。
- 点字放进上方字槽，再点一次取消，字槽右侧 × 一键清空；凑满即判定。
- 点错扣时间（普通 3 秒 / 困难 4 秒 / 地狱 5 秒）并计一次失误；倒计时耗尽即失败。
- 星级：零失误 3 星，失误 ≤2 次 2 星，其余 1 星。
- 连击：4 秒内连续消除累计连击，加分；每 3 连击奖励 +3 秒。棋盘上带时钟标记的字块消除后 +时间。
- 提示：高亮下一组该点的字并标出顺序（初始 3 次，每过一关 +1，最多 9 次）；洗牌：重新打乱字块位置。
- 三档难度：普通 / 困难 / 地狱（字块更多、时间更紧），进度分别保存；关卡由种子生成、无限递增。
- 每关都由真实词条组成，并有求解器保证始终可以清空：如果你消掉一个“合法但会让剩下的字凑不成词”的词，会温和提示且不扣分。
- 键盘：H 提示、S 洗牌、R 重开、Esc 清空字槽。

## 技术

- 纯 HTML5 Canvas + 原生 JavaScript，`index.html` + 题库 `data.js`，无依赖、无构建。
- PWA：`manifest.json` + `sw.js`（缓存全部文件，离线可玩），所有路径为相对路径。
- 适配 iOS 刘海/底部安全区，禁止双击缩放与页面回弹；只用 pointerdown，连点不丢。
- 性能：画布 DPR 上限 2；字块精灵与背景缓存到离屏画布；不使用逐帧 shadowBlur；空闲降帧（游戏中 10fps，有动画才满帧；菜单 20fps）；尺寸事件去抖；切后台暂停，带 rAF 看门狗。
- 更新：Service Worker 新版本立即接管（skipWaiting + clients.claim），页面自动刷新一次。
- 浅色 / 深色两套主题（菜单右上角切换）。
