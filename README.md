# 字消云散

一款汉字消消乐网页小游戏：字块分成几列叠放，只有每列最上面的字可以点，按顺序取字连成成语、古诗句（前两关是 2 字词语热身），连对即消除；上面的字消掉，下面的才会露出来。清空所有字块即可过关。

> 受同类汉字消除玩法启发的非官方作品，与任何商业游戏无关。题库为自行整理的常用词语、成语与诗句；全部图形、图标、音效均由代码实时生成，不包含任何第三方素材。

## 在线游玩

- 网址：https://tom2023n.github.io/zixiaoyunsan/
- **iPhone**：用 Safari 打开 → 分享 → “添加到主屏幕”，即可像 App 一样全屏启动；首次打开后可离线游玩。
- **安卓 / 电脑 Chrome**：地址栏右侧“安装”图标即可安装。

## 玩法

- **叠放取字**：每列的字从上往下叠着，只有最上面（压在最外层）的字能点；下面被压住的字会变暗，点了不算数，只会轻轻晃一下。
- 点字放进上方字槽，凑满后判定：**成语**按顺序 4 字、**诗句**按顺序 5 字、热身关**词语**按顺序 2 字。成语为主，每隔两关穿插一关诗句。
- **撤回**：把最后放进字槽的字放回它原来那一列的最上面（不限次数）；字槽右侧 × 一次全部撤回。
- 点错（凑出来不是词）扣时间（普通 3 秒 / 困难 4 秒 / 地狱 5 秒）并计一次失误，字自动放回原位；倒计时耗尽即失败。
- **死局检测**：如果字槽里已有的字开头怎么都凑不成词，会提示你撤回；如果你消掉一个“词没错但会让剩下的字没法消完”的词，会温和提示、不扣分并把字放回去。所以棋盘永远不会卡死。
- 星级：零失误 3 星，失误 ≤2 次 2 星，其余 1 星。
- 连击：4 秒内连续消除累计连击，加分；每 3 连击奖励 +3 秒。压在下面、带时钟标记的字块消除后 +5 秒。
- 提示：标出下一组该点的字和顺序（包括还被压着的字；初始 3 次，每过一关 +1，最多 9 次）；洗牌：用剩下的字重新叠一次（依然保证有解）。
- 三档难度：普通（下层字全部可见）/ 困难（压在第 3 层以下的字看不见）/ 地狱（只看得到紧挨着的下一层，字更多、时间更紧），进度分别保存；关卡由种子生成、无限递增。
- **保证有解**：每关先挑好真实词条，再按“倒着往上叠”的方式摆放（最后要消的词先压到底，第一个要消的词最后放到顶上），并用求解器从开局状态完整验证一遍。
- 键盘：H 提示、S 洗牌、R 重开、Z/退格 撤回、Esc 全部撤回。

## 技术

- 纯 HTML5 Canvas + 原生 JavaScript，`index.html` + 题库 `data.js`，无依赖、无构建。
- PWA：`manifest.json` + `sw.js`（缓存全部文件，离线可玩），所有路径为相对路径。
- 适配 iOS 刘海/底部安全区，禁止双击缩放与页面回弹；只用 pointerdown，连点不丢。
- 性能：画布 DPR 上限 2；字块精灵与背景缓存到离屏画布；不使用逐帧 shadowBlur；空闲降帧（游戏中 10fps，有动画才满帧；菜单 20fps）；尺寸事件去抖；切后台暂停，带 rAF 看门狗。
- 更新：Service Worker 新版本立即接管（skipWaiting + clients.claim），页面自动刷新一次。
- 浅色 / 深色两套主题（菜单右上角切换）。
