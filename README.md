# 字消云散

一款国风成语消除小游戏：成语拆成两半写在叠放的牌上，凑齐即消，层层揭开。画面与音效均由代码绘制生成。

在线试玩：https://tom2023n.github.io/zixiaoyunsan/ （可「添加到主屏幕」，离线可玩）

## 玩法
- 每张牌写着一个四字成语的**前两字或后两字**；横牌、竖牌多层叠放，被压住的牌是灰色、点不动，上层取走后才露出来。
- 左右两侧各有一叠「牌堆」，只能取最上面一张。
- 点到的牌进入下方 **4 格托盘**；托盘中凑齐同一成语的前后两半即自动消除，并显示完整成语。
- 4 格都放满却凑不出一对即失败；可用道具救场。
- 道具（每关限量：洗牌1、移出1、提示2、万能1）：**洗牌**（打乱场上牌位）、**移出**（把托盘里最多 3 张牌移到上方暂存区，点暂存区的牌可放回托盘）、**提示**（标出一对可取的牌）、**万能**（托盘第一张牌连同它的另一半——不论压在哪里——直接消除）。
- 无体力、无计时、无付费。连续过关从「童生」晋升到「状元」，榜文提示「再通过 N 关晋升」。

## 技术
- 单文件 Canvas 2D；关卡由「反向构造 + 求解器」生成，保证有解，且同一关内的半边不会产生歧义；成语库 400+。
- 静态层缓存、空闲降帧、DPR≤2、防抖 resize；PWA（Service Worker 缓存 `zixiaoyunsan-v4`）、iOS 适配。
- 日 / 夜两套主题：宣纸水墨 与 墨蓝朱砂金；象牙/玉质字牌、木质答案笺托盘、铜钱道具、牌匾关卡名、墨晕+印章消除动效、立轴展开结算。
